# NG Hive — сайт студии

Одностраничный сайт компании **NG Hive** — маленькой продуктовой студии
мобильных приложений.

Никаких сборщиков и зависимостей: обычные HTML, CSS и JavaScript.
Открывается двойным кликом по `index.html` и так же спокойно живёт
на GitHub Pages.

## Что внутри

```
index.html        вся страница
css/styles.css    оформление, светлая и тёмная темы
js/main.js        интерактив
assets/           логотип и шапка
```

## Что на странице

- Герой с живой сеткой сот на `<canvas>` — соты подсвечиваются под курсором
- Рассказ о студии, принципы работы, процесс и планы
- Три карточки приложений с макетами устройств:
  **WhatchAlarm** (умный будильник для Apple Watch),
  **ShopPing** (список покупок с напоминанием у магазина),
  **H.Collage** (коллажи из 2–10 фото)
- Форма связи (открывает почтовый клиент) и кнопка копирования адреса
- FAQ, подвал, кнопка «наверх»

## Приколюшки

## Локальный запуск

Достаточно открыть `index.html` в браузере. Если хочется по-настоящему,
с сервером:

```bash
python -m http.server 8777
```

и зайти на `http://localhost:8777`.

## Публикация на GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, ветка `master`, папка `/ (root)`.
Через минуту сайт будет по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Правки, которые делаются чаще всего

- **Почта для связи** — атрибут `data-mail` у кнопки `#mailCopy` в `index.html`
- **Тексты приложений** — секция `<section id="apps">`
- **Цвета** — переменные `--honey`, `--ink`, `--bg` в начале `css/styles.css`
- **Английская версия** — атрибут `data-en` у каждого переводимого элемента
