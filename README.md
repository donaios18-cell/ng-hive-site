# NG Hive — сайт студии

Одностраничный сайт компании **NG Hive** — маленькой продуктовой студии
мобильных приложений.

Никаких сборщиков и зависимостей: обычные HTML, CSS и JavaScript.
Открывается двойным кликом по `index.html` и так же спокойно живёт
на GitHub Pages.

## Что внутри

```
index.html        вся страница
css/styles.css    оформление, светлая и тёмная темы
js/main.js        интерактив
js/i18n.js        переводы на немецкий, французский, испанский и португальский
assets/           логотип и шапка
```

## Что на странице

- Герой с живой сеткой сот на `<canvas>` — соты подсвечиваются под курсором
- Рассказ о студии, принципы работы, процесс и планы
- Три карточки приложений с макетами устройств:
  **WhatchAlarm** (умный будильник для Apple Watch),
  **ShopPing** (список покупок с напоминанием у магазина),
  **H.Collage** (коллажи из 2–10 фото)
- Форма связи (открывает почтовый клиент) и кнопка копирования адреса
- FAQ, подвал, кнопка «наверх»

## Локальный запуск

Достаточно открыть `index.html` в браузере. Если хочется по-настоящему,
с сервером:

```bash
python -m http.server 8777
```

и зайти на `http://localhost:8777`.

## Где живёт сайт

Сайт опубликован в Cloudflare Pages, проект `nghive`, адрес — https://nghive.app
(и `www.nghive.app`). Рядом на том же домене живут сайты приложений:
`shopping.nghive.app`, `watch.nghive.app`, `collage.nghive.app`.

Старый адрес на GitHub Pages остался живым: в репозитории есть ветка `redirect`,
из которой GitHub раздаёт страницу-перенаправление на новый адрес. Эту ветку
трогать не нужно — она не имеет отношения к самому сайту.

## Как выложить изменения

Cloudflare берёт файлы не из GitHub, а из папки, которую ему отдают. Поэтому
после правок нужны два действия: обычный `git push` — чтобы код сохранился, и
выкладка — чтобы обновился сайт:

```bash
npx wrangler pages deploy . --project-name=nghive --branch=master
```

Команде нужны переменные `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`
(ключ лежит у Натальи, в репозиторий его класть нельзя). Выкладывать стоит
только `index.html`, `css/`, `js/` и `assets/` — папка `posts/` к сайту
отношения не имеет.

## Правки, которые делаются чаще всего

- **Почта для связи** — атрибут `data-mail` у кнопки `#mailCopy` в `index.html`
- **Тексты приложений** — секция `<section id="apps">`
- **Цвета** — переменные `--honey`, `--ink`, `--bg` в начале `css/styles.css`
- **Переводы** — английский текст прямо в `index.html` и в атрибуте `data-en`, русский в `data-ru`,
  остальные языки в `js/i18n.js`, где ключом служит та же английская строка.
  Поменяли английский текст — поменяйте ключ и в `js/i18n.js`, иначе там покажется английский.
- **Язык по умолчанию** — английский; если посетитель выбрал другой язык в меню, сайт это запоминает
